## 实施任务

### 1. 统一分段时间轴

- [x] 1.1 新增纯 Kotlin 圈视频时间轴模型：输入圈窗口、分段起点和时长，输出覆盖区间、gap、播放切片、导出切片及 `FULL/PARTIAL/NONE`。
- [x] 1.2 修改 `LapPlaybackLoader`，让详情页、全屏页和导出获得同一份分段时间轴，不再用首段起点加单个 duration 判断整圈覆盖。
- [x] 1.3 新增 `VideoTimelinePlanTest`，覆盖单段、两段连续、短 gap、明显 gap、圈头/圈尾缺失、完全无覆盖和兼容旧路径。

### 2. 跨段播放

- [x] 2.1 将 `LapVideoPanel` 从单 `videoFilePath` 改为消费时间轴分段列表，支持跨段 seek、播放和圈末暂停。
- [x] 2.2 收敛全屏播放状态机：播放、拖动和 overlay 都以统一 wall-clock 时间轴为准，短切段 gap 快速跨越，真实缺失画面显示明确提示。
- [x] 2.3 重做全屏底部控制区：常驻播放/暂停、分段时间轴和导出入口，移除隐藏的双击主操作依赖及顶部悬浮“⬇”按钮。

### 3. 跨段导出

- [x] 3.1 将 `VideoExportService` 的跨段拒绝改为按 `ExportSlice` 读取目标圈涉及的局部源片段。
- [x] 3.2 扩展 `VideoExportPipeline`，在单次输出编码中依次消费多个源片段，并保持 overlay 使用原始 wall-clock 对齐。
- [x] 3.3 定义 gap 输出策略：短切段间隙压缩；真实缺失区间生成明确占位画面或在导出前提示，不得无说明地产生时间错位。
- [x] 3.4 新增跨段导出计划测试，覆盖段边界、裁剪范围、输出时长、gap 压缩和 overlay wall-clock 映射；取消与源异常复用 Service 既有清理/失败路径。

### 4. 导出反馈体验

- [x] 4.1 导出前展示当前圈完整性和跨段状态；不可导出时给出具体原因，不使用笼统 Toast。
- [x] 4.2 将阻塞式全屏进度遮罩改为可取消的轻量状态面板；失败保留原因和重试入口。
- [x] 4.3 导出成功后显示“查看 / 分享 / 完成”，不自动拉起系统分享页。

### 5. Session 录像管理

- [x] 5.1 增加仓库层录像统计结果（分段数、存在文件数、总字节数），以 `video_segments` 为主、旧 session 字段为兼容 fallback。
- [x] 5.2 将通栏红色“删除本场视频”迁到 Session 顶部更多菜单，文案改为“删除本场全部录像”。
- [x] 5.3 删除确认界面显示分段数、可释放空间并明确保留成绩；删除完成后刷新分段、播放入口和统计状态。
