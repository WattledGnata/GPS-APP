# 监控页面与性能测试页面需求文档

## 1. 文档概述

本文档详细描述 GPS Test 应用中两个核心功能模块的需求和设计规范，包括监控模块（MonitorView）和性能测试模块（PerformanceView）。监控模块负责实时 GPS 数据展示和设备连接管理，性能测试模块则提供完整的测试执行、历史记录查看和结果分享功能。

性能测试模块由多个关联页面共同组成，包括性能测试入口页面、测试执行页面、历史记录列表、历史记录详情、分享预览页面以及自定义测试配置弹窗。本文档将逐一说明各页面的功能需求、交互设计和数据流向。

---

## 2. 监控模块功能需求

### 2.1 页面定位与目标

监控模块是应用的实时数据展示中心，承担设备连接状态显示、GPS 定位信息实时更新、以及设备管理等核心功能。页面设计采用深色霓虹风格，为用户提供清晰直观的数据阅读体验，营造专业的汽车仪表氛围。

### 2.2 设备连接管理

**设备扫描功能**：应用启动后自动开始扫描周围可连接的 BLE 设备，扫描过程中在界面上显示扫描动画，向用户反馈当前状态。扫描持续进行直到用户选择连接设备或离开页面。

**设备列表展示**：当应用处于未连接状态时，页面底部显示可用设备列表。列表中的每个设备项包含设备名称和 UUID 信息，用户点击任意设备项即可发起连接请求。对于已发现的模拟设备（调试模式），列表中以特殊标识区分。

**连接状态指示**：页面顶部和连接状态横幅中实时显示当前连接状态。已连接状态显示为绿色指示灯和「已连接」文字，未连接状态显示为红色指示灯和「未连接」文字。连接成功后还会显示已连接设备的名称。

**设备断开功能**：已连接状态下，页面提供「断开连接」按钮，用户点击后可主动断开与当前设备的连接。断开后页面自动刷新设备列表，进入设备搜索状态。

**模拟设备支持**（调试功能）：通过连续点击页面标题「GPS 监控」五次，可激活模拟设备模式。此时设备列表中会显示预设的模拟设备，用户可选择连接模拟设备进行功能和 UI 测试，无需真实硬件。

### 2.3 实时数据展示

| 数据项 | 显示格式 | 单位 | 描述 |
|--------|----------|------|------|
| 速度 | 保留一位小数 | km/h | 当前行驶速度，带仪表盘视觉效果 |
| 纬度 | 保留六位小数 | 度 | 当前地理位置的纬度坐标 |
| 经度 | 保留六位小数 | 度 | 当前地理位置的经度坐标 |
| 航向 | 整数角度 | 度 | 当前行驶方向，范围 0-360° |
| 海拔 | 保留一位小数 | M | 海平面以上高度 |
| 卫星数量 | 整数 | 个 | 当前已定位的卫星数量 |
| 定位状态 | 文本描述 | — | 「GPS 已定位」或「未定位」 |
| 信号质量 | 文本描述 | — | 基于定位精度计算的质量指标 |
| 水平精度 | 保留一位小数 | m | HDOP 计算的水平位置精度 |
| 垂直精度 | 保留一位小数 | m | VDOP 计算的垂直位置精度 |
| 更新时间 | HH:mm:ss | — | 最后一次数据更新的时间戳 |

### 2.4 UI 布局与视觉设计

页面采用全屏深色主题设计，背景色为 #0A0A0E，辅以网格装饰线条增强科技感。具体布局结构如下：

**顶部导航区域**：包含页面标题「GPS 监控」和串口监视器入口按钮。标题采用渐变色（霓虹蓝到紫色）增强视觉层次。导航区域底部有细微的渐变分割线。

**连接状态横幅**：位于导航区域下方，显示当前连接状态、设备名称（如已连接）和断开连接按钮。横幅采用半透明深色背景（白色 12% 透明度）和圆角设计。

**速度仪表盘区域**：已连接状态下显示核心的圆形速度仪表。仪表采用 270 度弧形进度条设计，外圈有刻度线（每 5 格有长刻度），中心显示当前速度数值。仪表最大量程根据测试模式动态调整。

**卫星与信号区域**：仪表盘下方并排显示两个数据卡片。「卫星数量」卡片以信号强度条可视化展示当前信号水平，「信号质量」卡片显示定位状态和精度信息。

**数据网格区域**：速度仪表下方以两列网格形式展示航向、精度、海拔、更新时间等次要数据。每个数据项包含图标、标签和数值，采用深色卡片设计。

**设备列表区域**：未连接状态下替代数据展示区域，显示滚动列表。列表项包含设备图标、名称、UUID 和连接箭头。扫描动画位于列表上方。

## 3. 性能测试模块功能需求

### 3.1 模块组成概述

性能测试模块由以下页面和组件共同构成：

| 页面/组件 | 类型 | 用途 |
|-----------|------|------|
| PerformanceView | 主页面 | 测试项目选择入口 |
| TestActiveView | 全屏覆盖 | 测试执行和实时数据展示 |
| HistoryListView | 全屏覆盖 | 历史测试记录列表 |
| HistoryDetailView | 全屏覆盖 | 单条测试记录详情分析 |
| SharePreviewView | 全屏覆盖 | 分享预览和保存功能 |
| ShareResultView | 嵌入组件 | 分享结果图片生成 |
| CustomTestSetupView | 弹出表单 | 自定义测试参数配置 |

### 3.2 性能测试入口页面（PerformanceView）

页面通过 SegmentedPicker 控件提供两种测试类别切换：

**内置测试**：包含预设的标准性能测试项目，按类型分为加速测试和刹车测试两个区域。

**自定义测试**：允许用户创建个性化的测试配置，包括自定义速度目标、距离目标或刹车测试参数。

**内置加速测试**：

| 测试项目 | 描述 | 图标 |
|----------|------|------|
| 0-50m | 测试从静止加速到通过 50 米距离的用时 | gauge.with.needle |
| 0-100m | 测试从静止加速到通过 100 米距离的用时 | gauge.with.needle |
| 0-200m | 测试从静止加速到通过 200 米距离的用时 | gauge.with.needle |
| 0-400m | 测试从静止加速到通过 400 米距离的用时 | gauge.with.needle |
| 0-50km/h | 测试从静止加速到 50km/h 的用时 | gauge.with.needle |
| 0-100km/h | 测试从静止加速到 100km/h 的用时 | gauge.with.needle |
| 0-200km/h | 测试从静止加速到 200km/h 的用时 | gauge.with.needle |

**内置刹车测试**：

| 测试项目 | 描述 | 图标 |
|----------|------|------|
| 100-0km/h | 从 100km/h 减速到静止的制动距离 | hand.raised.fill |
| 200-0km/h | 从 200km/h 减速到静止的制动距离 | hand.raised.fill |
| 60-0km/h | 从 60km/h 减速到静止的制动距离 | hand.raised.fill |
| 80-0km/h | 从 80km/h 减速到静止的制动距离 | hand.raised.fill |

**测试启动流程**：用户选择测试项目后，首先检查设备连接状态。若未连接则弹出 Alert 提示「请先连接设备后再开始测试」。若设备已连接，则设置测试模式和目标，调用 armTest() 方法触发测试准备，最后跳转到 TestActiveView 页面。

**历史记录入口**：页面右上角提供「历史记录」按钮，点击后跳转到 HistoryListView。

### 3.3 测试执行页面（TestActiveView）

测试执行页面是性能测试的核心环节，提供实时数据展示、视频录制和测试控制功能。

**实时数据展示功能**：

**速度仪表**：圆形进度条式速度表，根据测试类型动态调整最大量程。加速测试默认 120km/h，0-200km/h 测试使用 220km/h 量程。仪表带有刻度线和动态光晕效果。

**G-Force 显示**：圆形 G-Force 指示器，实时显示车辆加速度产生的 G 力。指示点根据 G 力值在圆内上下移动，显示范围为 -1G 到 +1G。

**实时数据网格**：显示加速 G 值、纵向加速度（m/s²）和行驶距离（m）三个核心指标。

**分段成绩列表**：滚动列表显示已完成的分段成绩，每段显示目标名称、成绩用时（加速测试）或距离（刹车测试）。列表支持横竖屏自适应布局。

**视频录制功能**：

**预览模式**：用户点击「录制」按钮后开启相机预览，屏幕背景变透明，可见相机实时画面。

**录制模式**：预览状态下再次点击开始录制，录制按钮变为红色方块。测试完成后自动停止录制。

**视频保存**：录制停止后视频文件保存到本地，路径信息关联到测试记录，可在历史详情中回放。

**测试状态管理**：页面根据 BLEManager 的状态显示不同的提示：

**就绪状态**：显示绿色「就绪」提示和具体的启动指令，如「请加速至 60 km/h」或「等待起步」。

**测试中状态**：显示测试进行中的动态提示，指示灯闪烁。

**完成状态**：测试完成后显示结果汇总视图，包括完成标识、核心成绩（时间或距离）以及「结果已自动保存」提示。完成时屏幕会有绿色闪烁反馈动画。

**完成后续操作**：

**返回按钮**：点击后重置测试数据并返回性能测试页面。

**分享按钮**：点击后打开分享预览视图，可将测试结果分享到其他应用或保存到相册。

**再次测试按钮**：点击后重新触发测试准备，无需返回选择页面。

### 3.4 历史记录列表页面（HistoryListView）

历史记录列表页面展示所有历史测试记录，支持分类筛选和删除操作。

**分类功能**：

**测试类别筛选**：通过 SegmentedPicker 切换「内置测试」和「自定义测试」两个类别。

**类型筛选**：通过横向滚动按钮组筛选「全部」「加速」「刹车」三种类型。

**列表展示**：每条记录显示类型图标、测试项目名称、测试时间和成绩结果。支持左滑删除操作。

**空状态处理**：无记录时显示「暂无测试记录」提示和时钟图标。

**删除功能**：左滑记录项显示删除按钮，点击后弹出确认对话框「是否删除该条测试记录？删除后不可恢复。」

### 3.5 历史记录详情页面（HistoryDetailView）

历史记录详情页面提供单条测试记录的完整数据分析，包含图表分析和摘要信息。

**核心成绩展示**：页面顶部显示测试结果（时间或距离）和测试项目名称，采用大号字体突出显示。

**视频回放功能**：如果测试关联了视频文件，显示视频播放器组件，支持回放测试过程。

**综合图表分析**：

**速度曲线**：使用 Swift Charts 绘制速度随时间变化的曲线图，支持区域填充显示。

**G 值曲线**：绘制纵向 G 值随时间变化的曲线图，采用滑动平均算法进行平滑处理，减少数据噪点。

两个图表均支持自适应刻度范围，X 轴显示时间（秒），Y 轴显示对应数值。

**分段成绩列表**：逐项显示各个分段目标的成绩，包括用时（或距离）和行驶距离。

**测试摘要信息**：包含测试日期、测试类型、最终结果、极速/初速、最大 G 值等关键指标。

**分享功能**：右上角提供分享按钮，点击后跳转到 SharePreviewView。

### 3.6 分享预览页面（SharePreviewView）

分享预览页面提供测试结果的分享和保存功能。

**预览展示**：页面嵌入 ShareResultView 组件，展示生成的分享图片效果。图片包含应用品牌标识、测试类型、测试时间、测试项目、核心成绩、极速/初速、最大 G 值和总距离等信息。

**分享图片设计**：分享结果图片采用深色背景配紫色渐变装饰，包含以下元素：顶部应用名称和图标、分隔线、测试类型标签、时间戳、测试项目名称、醒目的大号成绩数值、底部三个数据卡片（极速/初速、最大 G 值、总距离）、以及底部「Generated by BlazePush」品牌标识。

**保存到相册功能**：底部提供「保存结果至相册」按钮，点击后执行以下流程：请求相册写入权限、生成当前视图的高清图片、将图片保存到系统相册、保存成功显示绿色勾选图标和「已保存到相册」Toast 提示、保存失败显示错误提示。

**关闭功能**：右上角提供关闭按钮，点击后退出分享预览页面。

### 3.7 自定义测试配置弹窗（CustomTestSetupView）

自定义测试配置弹窗以表单形式收集用户输入的测试参数。

**测试类型选择**：通过 SegmentedPicker 选择测试类型，包括「速度测试」「距离测试」「刹车测试」三种选项。切换类型时自动重置默认参数值。

**参数设置**：

**速度测试**：需要设置起始速度（默认 0 km/h）和目标速度（默认 100 km/h）。

**距离测试**：需要设置目标距离（默认 400 m），起始距离固定为 0。

**刹车测试**：需要设置起始速度（默认 100 km/h），结束速度固定为 0。

所有数值输入采用数字键盘，实时校验输入合法性。

**输入验证逻辑**：

速度测试：目标速度必须大于起始速度。

距离测试：目标距离必须大于 0。

刹车测试：起始速度必须大于 0。

重复检测：检测配置是否与内置测试或已有自定义测试重复，如重复则弹出提示。

**保存与启动**：验证通过后，保存自定义预设到本地（通过 BLEManager），设置测试参数，触发测试准备，然后关闭弹窗并跳转到 TestActiveView 页面。

**取消功能**：左上角提供「取消」按钮，点击后关闭弹窗不保存任何配置。

## 4. 数据模型定义

### 4.1 BLEManager 核心属性

两个模块均依赖 BLEManager 单例进行数据管理和状态控制：

| 属性 | 类型 | 用途 |
|------|------|------|
| isConnected | Bool | 设备连接状态 |
| connectedDeviceName | String? | 已连接设备名称 |
| gpsData | GPSData | 实时 GPS 数据 |
| discoveredPeripherals | [CBPeripheral] | 发现的外设列表 |
| mockDevices | [MockDevice] | 模拟设备列表 |
| customPresets | [CustomPreset] | 自定义测试预设 |
| testMode | TestMode | 当前测试模式 |
| accelTarget | AccelerationTarget | 加速测试目标 |
| brakingTarget | BrakingTarget | 刹车测试目标 |
| isTesting | Bool | 测试进行状态 |
| isBraking | Bool | 刹车测试进行状态 |
| isTestArmed | Bool | 测试就绪状态 |
| history | [TestHistoryItem] | 历史测试记录 |
| currentSegments | [TestSegment] | 当前测试分段成绩 |
| currentDistance | Double | 当前行驶距离 |

### 4.2 测试历史记录模型

```swift
struct TestHistoryItem: Identifiable {
    let id: UUID
    let type: String           // "加速" / "刹车" / "Custom Braking"
    let detail: String         // 测试项目名称
    let result: String         // 成绩字符串
    let timestamp: Date        // 测试时间
    let segments: [TestSegment] // 分段成绩
    let dataPoints: [TestDataPoint] // 采样数据点
    let videoPath: String?     // 视频文件路径
}
```

### 4.3 采样数据点模型

```swift
struct TestDataPoint: Identifiable {
    let id = UUID()
    let timeOffset: Double     // 时间偏移（秒）
    let speed: Double          // 速度（km/h）
    let gForce: Double         // G-Force 值
    let distance: Double       // 行驶距离（米）
}
```

### 4.4 自定义测试预设模型

```swift
struct CustomPreset: Identifiable {
    let id: UUID
    let type: CustomTestType   // 测试类型
    let startValue: Double     // 起始值
    let endValue: Double       // 结束值
    let title: String          // 显示名称
}
```

## 6. 错误处理与用户反馈

### 6.1 设备连接相关

**设备未连接时启动测试**：弹出系统 Alert 对话框，标题为「设备未连接」，内容为「请先连接设备后再开始测试」。

**蓝牙未开启**：系统自动弹窗提示用户开启蓝牙。

**连接失败**：设备列表项显示连接中状态（ProgressView），超时后自动恢复可点击状态。

### 6.2 自定义测试配置相关

**参数校验失败**：弹出 Alert 提示具体的校验错误信息，如「目标速度必须大于起始速度」「该测试项目已存在于【内置测试】中」等。

### 6.3 相册保存相关

**权限被拒绝**：显示 Toast 提示「请在设置中允许访问相册」。

**保存失败**：显示 Toast 提示「生成图片失败」或保存失败的具体原因。

### 6.4 状态视觉反馈

**就绪提示**：绿色文字和图标，显示具体的启动指令。

**测试中提示**：带闪烁圆点的动态提示，反映当前测试状态。

**完成提示**：绿色闪烁反馈动画，随后显示结果汇总。

**保存成功提示**：绿色勾选图标和「已保存到相册」文字，持续 2 秒后自动消失。

### 7.1 配色方案
