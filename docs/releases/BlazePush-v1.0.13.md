# BlazePush v1.0.13

发布日期：2026-09-01

定位：GPS 时间同步与 0–100 成绩可信度修复。建议直接覆盖安装旧版本，不要卸载，以保留历史 Session、圈速、性能成绩和录像关联数据。

## 本次更新

- BLE 每次连接成功后主动读取 GPS 时间特征；未取得时间时按退避节奏持续重试，补上设备整点广播之外的时间数据真空。
- GPS 详情页增加当前 GPS 时间与同步状态，便于现场确认计时链路是否真正就绪。
- 0–100 完整保留原始诊断遥测，同时单独记录最终有效成绩窗口；耗时、距离、分段、速度曲线、G 曲线、平均 G 和峰值 G 统一使用同一个窗口。
- 修正历史成绩把整段准备/失败尝试画进曲线的问题；没有新窗口字段的旧记录会只读重建最后一次完整成绩窗口，不修改原始记录。
- 速度曲线显示真实最高速度，0–100 绘图上限至少为 100 km/h，不再把 IQR 异常值边界显示为最高速度。
- G 曲线按加速/制动方向使用完整纵向量程，并显示上、中、下三档数值和零基线，更容易观察真实加速度回落。
- 性能测试开始时冻结设备身份，按“用户别名 → 真实设备名 → 地址”保存新成绩，避免完成瞬间断连后落入硬编码名称。

## 使用建议

1. 请直接覆盖安装，不要卸载旧版本。
2. 连接 GPS 后可在 GPS 详情页确认时间已同步，再开始圈速或性能测试。
3. 旧成绩可看到修正后的窗口曲线，但旧记录中已经保存的设备名称不会被追溯改写。
4. 如遇异常，请保留 App 数据与完整原始遥测，并从诊断入口上传日志。

## 验收边界

- 已完成领域、数据层和性能结果页单元测试，Debug 覆盖安装与 vivo 旧成绩回放通过。
- 2026-09-01 路测证明 UUID 4 主动补读可使状态进入 `SYNCHRONIZED`，并可完成一次 0–100。
- 新窗口字段、sample 数量一致和新设备快照仍需下一次新 0–100 成绩做完整闭环核对；本次不把旧记录回放当作该持久化路径的实车证明。
- G 曲线只表达 GPS 推导出的纵向加速度变化，不会仅凭 GPS 自动判断或标注具体挡位。
