# BlazePush v1.0.12

发布日期：2026-08-29

定位：赛道现场稳定性与易用性更新。建议直接覆盖安装旧版本，不要卸载，以保留历史 Session、圈速和录像关联数据。

## 本次更新

- 强化 GPS 断联与重连保护：GPS 设备中途关机、超距或重新连接后，计时会等待新一轮可靠数据同步，不再把旧时间基准拼进当前圈。
- START 后立即创建 Session；GPS 尚未稳定时仍可先准备录像，可靠定位恢复后再从完整起终点穿线开始计圈。
- 每次点击扫描都会检查蓝牙权限；已连接设备会在扫描面板中明确显示，扫描会在超时后自动结束，不再出现假扫描或重复连接入口。
- 圈速页面中文化并重构状态表达，显示本场最佳与理论最佳；GPS 新鲜度、当前速度和录像选择更直观。
- 新增宁波国际赛道和天津 V1 国际赛车场完整预设，并扩大预设赛道起终点门线的容错覆盖。
- 支持导出单圈或整场 Session 的 RaceLogic VBO 文件，便于 RaceChrono/VBOX 等工具复盘。
- 强化异常退出后的遥测恢复、刷盘和圈速置信度处理，保留原始证据并避免不可靠圈速自动参与最佳圈、播报或上传。

## 使用建议

1. 请直接覆盖安装，不要卸载旧版本。
2. 出发前确认蓝牙设备已连接、GPS 状态稳定，再进行正式计时。
3. GPS 中途断电或重连后，等待页面重新显示定位稳定；恢复后的第一个可靠起终点穿线用于重新建立计圈基准。
4. 如遇异常，请保留 App 数据并从诊断入口上传日志。

## 验收边界

- 已完成自动化测试、Release 构建、APK 身份与签名检查。
- 当前无指定 BLE GPS 硬件在手，本版本尚未完成 GPS 关机重开、超距返回、手机蓝牙关开等实车闭环；现场使用时请保留诊断日志。
