# ESP32 蓝牙测试设备

## 背景

本GPS测试应用依赖外部RaceChrono GPS硬件设备，在室内开发环境存在以下限制：

1. **GPS信号限制**: 室内无法接收到GPS卫星信号
2. **测试场景受限**: 只能测试蓝牙连接，无法验证完整的GPS数据接收流程
3. **开发效率低**: 每次测试需要到户外，等待GPS定位
4. **调试困难**: 无法在室内调试GPS数据解析和处理逻辑

## 解决方案

使用ESP32蓝牙芯片开发测试设备，模拟RaceChrono GPS设备的BLE广播和数据发送。

## ESP32 固件需求

### 硬件要求

- **芯片**: ESP32 (任何型号，如ESP32-WROOM-32)
- **蓝牙**: BLE 4.0+ 支持
- **电源**: USB供电或电池
- **指示灯**: LED显示工作状态

### 固件功能

#### 1. BLE广播

```
SERVICE_UUID: 00001ff8-0000-1000-8000-00805f9b34fb
DEVICE_NAME: "RaceChrono GPS" 或 "ESP32 GPS Test"
```

#### 2. GATT服务

实现与RaceChrono相同的服务和特征���：

**主服务**:
- UUID: `00001ff8-0000-1000-8000-00805f9b34fb`

**特征值**:
1. **GPS主数据**
   - UUID: `00000003-0000-1000-8000-00805f9b34fb`
   - 属性: Notify
   - 数据长度: 20字节
   - 发送频率: 1-25 Hz可配置

2. **GPS时间数据**
   - UUID: `00000004-0000-1000-8000-00805f9b34fb`
   - 属性: Notify
   - 数据长度: 3字节
   - 发送频率: 1 Hz

#### 3. 数据模拟

**GPS主数据格式 (20字节)**:
```
[0-1]   同步位 (0xFFFF)
[2-3]   时间戳 (ms)
[4]     定位质量 (0-无定位, 1-GPS, 2-DGPS)
[5]     卫星数量 (0-12)
[6-9]   纬度 (1/10,000,000度)
[10-13] 经度 (1/10,000,000度)
[14-15] 海拔高度 (m, above MSL)
[16-17] 速度 (km/h)
[18-19] 方位角 (度)
```

**模拟场景**:
1. **静态测试**: 固定位置，速度为0
2. **加速测试**: 速度从0逐渐增加到100 km/h
3. **刹车测试**: 速度从100逐渐减少到0 km/h
4. **行驶模拟**: 速度在20-80 km/h之间波动

**GPS时间数据格式 (3字节)**:
```
[0] 同步位 (0xFE)
[1-2] 时间和日期编码
```

#### 4. 配置接口

通过串口或蓝牙特征值配置：
- 数据发送频率 (1/5/10/25 Hz)
- 测试场景选择
- 卫星数量设置
- HDOP值设置
